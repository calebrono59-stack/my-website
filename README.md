# Money Tracker 💰

A modern dark-themed personal finance tracking website built using HTML, CSS and JavaScript.

## About the Project

Money Tracker helps users manage their finances by recording income and expenses, calculating their balance and keeping track of transactions.

## Features

- Modern dark-themed dashboard
- Income tracking
- Expense tracking
- Automatic balance calculation
- Add new transactions
- Edit and delete transactions
- Save transactions using Local Storage
- Transaction dates

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Use

1. Open the website.
2. Enter a transaction description.
3. Enter the amount.
4. Select Income or Expense.
5. Click Add Transaction.
6. View your updated balance and transaction history.
